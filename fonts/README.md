# Fonts

`dp_korean_gothic.ttf` and `dp_korean_pen.ttf` are Korean fonts for the 한국어 language option:
subsets (the 2,350 KS X 1001 Hangul syllables, ASCII and common punctuation) of **NanumBarunGothic**
and **NanumPen**, Copyright (c) 2010 NAVER Corporation, renamed as the SIL Open Font License requires
for modified versions (the names "Nanum" are Reserved Font Names). Licensed under the SIL Open Font
License 1.1: see `OFL.txt`. They are not sold, and stay under the same license.
