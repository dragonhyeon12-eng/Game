DREAM PROTOCOL

A first-person lucid dream that slowly stops being yours: a summer city, a yellow maze, a pool with no bottom, a basement that gets smaller, a roof above the clouds. It runs right here in this tab, with the Godot engine built in. Nothing to install.

About 17 MB to load the first time.
W A S D move, mouse look
E interact
Shift run C crouch
Space jump / swim up
Q hold: picture something
T hold: try to wake up
N notebook
P pause Esc free the mouse

Best on a desktop browser with a keyboard, a mouse and headphones. Click the game to capture the mouse. Your progress is saved in this browser. Prefer the full version with all the lighting effects? Get Godot 4.7 and the project files, import project.godot and press Run.
